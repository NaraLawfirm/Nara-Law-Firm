NARA LAW FIRM — WEBSITE PROTOTYPE

Cara melihat:
1. Buka file index.html di Google Chrome / Microsoft Edge.
2. Website akan tampil dengan opening animation dan scroll animations.

Catatan:
- Data kontak, nama tim, alamat, artikel, dan bidang praktik masih berupa contoh/placeholder.
- Logo NARA sudah dipasang dari file yang diberikan.
- Font menggunakan Google Fonts saat online; website tetap terbuka jika font tidak tersedia.


=========================================================
CARA MENGGANTI KONTAK NARA
=========================================================
Buka folder: js
Lalu buka file: config.js

Edit bagian NARA_CONTACT. Contoh:
whatsapp: "6281234567890",
phoneDisplay: "+62 812-3456-7890",
email: "office@nara-lawfirm.com",
address: "Jl. Contoh No. 10, Semarang, Jawa Tengah",
instagram: "https://instagram.com/akun_nara",
website: "https://www.nara-lawfirm.com"

Setelah disimpan, refresh index.html di browser.
Anda tidak perlu mengedit HTML untuk mengganti data kontak.

LOGO TRANSPARAN
=========================================================
Logo yang dipakai website adalah:
images/nara-logo-transparent.png

diletakkan di atas background website tanpa kotak hitam.
